## 👋 About Me

I'm **Kamalakannan**, a Data Engineer passionate about building reliable, scalable, and efficient data solutions that turn raw data into meaningful insights.

My work and interests span data ingestion, transformation, pipeline orchestration, distributed processing, cloud data platforms, and analytics engineering. I'm also interested in exploring how AI and Generative AI can enhance data workflows and make data more accessible and useful.

- 💼 **Currently:** Data Engineer at Genpact
- ⚙️ **Core expertise:** Databricks, PySpark, SQL, and data pipeline development
- 🔄 **Engineering focus:** ETL/ELT, data transformation, workflow orchestration, and performance optimization
- ☁️ **Cloud & platforms:** AWS and modern data platforms
- 🤖 **Exploring:** AI/GenAI integration with data engineering
- 🎯 **Driven by:** Building dependable data systems and continuously improving engineering practices
- 🤝 **Open to:** Collaborating on meaningful data engineering and open-source projects

> I enjoy solving the engineering problems behind good data: moving it reliably, transforming it efficiently, and making it ready for decisions.
